# Segurança

O BacenTools é um site estático: não guarda dados de usuários e não tem servidor próprio.

Achou uma vulnerabilidade, como um script injetado, uma dependência vulnerável ou dados expostos? Relate de forma **privada** em [Security › Report a vulnerability](https://github.com/vieiraes/bacentools/security/advisories/new). Não abra issue pública.
