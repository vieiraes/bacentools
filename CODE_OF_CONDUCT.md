# Código de Conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo:
- **Respeito:** trate todas as pessoas com respeito, sejam quais forem a experiência, a identidade ou a origem de cada uma.
- **Crítica construtiva:** critique ideias e código, nunca pessoas.
- **Nada de assédio:** assédio, ofensas e exposição de dados pessoais não são tolerados.

Se algo te incomodar, fale com o mantenedor, [@vieiraes](https://github.com/vieiraes), por uma issue privada de segurança ou pelo perfil no GitHub.
